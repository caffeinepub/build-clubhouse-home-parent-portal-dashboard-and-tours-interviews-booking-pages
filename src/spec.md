# Specification

## Summary
**Goal:** Refresh the Clubhouse app visuals by replacing the homepage hero image with the uploaded “Cool Kidz Club” artwork and applying the uploaded colorful handprints image as the app-wide background while keeping content readable.

**Planned changes:**
- Add the uploaded “Cool Kidz Club” artwork as a static frontend asset and use it as the Clubhouse home page hero image (replacing the current generated hero image), keeping it responsive within the rounded hero container.
- Add the uploaded colorful handprints image as a static frontend asset and apply it as the background across the main app shell/pages (Home, Parent Portal, Tours), with styling (e.g., overlay/opacity) to maintain readability and good performance.

**User-visible outcome:** Users see the “Cool Kidz Club” artwork as the new homepage hero image, and the app’s main pages display a colorful handprints background without sacrificing text and UI readability.
